# Product

## Register

product

## Platform

web

## Users

Software teams already using AI coding agents such as Codex and Claude. The primary users are developers working on the same repository, alongside technical leads and teammates who need to understand, steer, and review agent work while it is still happening.

## Product Purpose

CoDev is a hosted multiplayer agentic IDE. It gives people and multiple AI agents one shared browser workspace containing the repository, active sessions, runtime, conversations, changes, and review context. Success means a first-time visitor immediately understands that teammates can run Codex and Claude in parallel, see both agents work, steer either session, avoid collisions, and review the result together.

## Brand Personality

Clear, collaborative, and alive. CoDev should feel precise enough for serious engineering work, human enough for a team room, and visibly active without becoming noisy or theatrical.

## Anti-references

- A generic technical SaaS page whose headline could describe any collaboration tool.
- Dense enterprise copy that explains architecture before showing the product.
- Dark terminal cosplay, neon AI gradients, glassmorphism, or decorative code aesthetics.
- Editorial-tech styling built from italic serif headlines, tiny mono labels, numbered section scaffolding, and oversized whitespace.
- A downloadable desktop-product presentation; CoDev is a hosted website.

## Design Principles

1. Name the category immediately: multiplayer IDE for people and AI agents.
2. Show the differentiator before explaining it: two people and multiple agents working concurrently in one shared repository.
3. Make activity legible at a glance: ownership, agent identity, current work, and shared state should read without technical interpretation.
4. Prefer a short product story over exhaustive feature coverage: understand, watch, steer, review, start.
5. Keep the interface energetic through real state and purposeful motion, not decorative effects.

## Accessibility & Inclusion

Meet WCAG 2.2 AA contrast and interaction requirements. Keep meaning-bearing text at readable sizes, preserve keyboard and touch access, provide visible focus states, and include a complete `prefers-reduced-motion` presentation that communicates the simultaneous Codex and Claude workflow without animation. Do not rely on color alone to convey agent, user, or status identity.
